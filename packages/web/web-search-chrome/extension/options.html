dsh-lean-chat bridge

This extension runs the chat app's searches and browser steps in this browser, using its cookies. Point it at the address the app prints on startup.

Optional. Load this extension in several Chrome profiles and give each a label — the model can then pick which profile to browse in (right logins, right accounts).

Off by default: the model can only read pages here. Turn this on only for a profile whose logins you are comfortable letting the model act with — a guest or test profile is a good first choice.
